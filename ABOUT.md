## 加长版

**中文**

dsh-desktop-acrylic 为 DeepSeek Harness (DSH) 桌面端带来 Tokyo Night 的暗色与亮色两套主题。它们是注册进内置主题运行时的真实皮肤（而非 CSS 覆盖），切换主题即切换运行时偏好本身。主题之上叠加了完整的亚克力体验：半透明画布、磨砂对话框面板、模糊浮层，以及一层由蓝 / 紫 / 青构成的柔和材质色场；另有可搜索的下拉框，从本机已安装的等宽字体（含 Nerd Font / Powerline 变体）中挑选界面字体与代码字体。附带构建期自检与运行诊断上报，MIT 许可。

**English**

dsh-desktop-acrylic brings Tokyo Night's dark and light themes to DeepSeek Harness (DSH) Desktop. Both skins are real themes registered into the built-in theme runtime — not CSS overrides — so switching themes switches the runtime preference itself. On top sits a full acrylic experience: translucent canvas, frosted dialog panels, blurred floating surfaces, and a soft blue/purple/cyan material field underneath. Searchable pickers let you choose the UI and code fonts from the monospace families actually installed on your machine (Nerd Font / Powerline variants included). Build-time self-checks and runtime diagnostics are built in. MIT licensed.
